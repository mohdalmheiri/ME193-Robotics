# ME193-Robotics

My code for ME193 (AI in Mobile Robots, Fall 2026). The course is about
using AI on a laptop (computer vision, sound, trained models and controllers)
to drive real robots, and this repo holds my assignments, each in its own
folder with a README. It's a fork of the class repo, so it also carries the
shared class resources.

## Layout

- [`Mohammed's Projects/`](./Mohammed%27s%20Projects) — my assignments
  and coursework, one folder per assignment. Its README lists them and
  explains how to set up the Python environment.
- [`Public stuff/`](./Public%20stuff) — the shared class resources (synced
  from the upstream class repo): common libraries, demos, and tools.
